# TDR Simulació de comunicació satel·litaria by Kai Pinós Vogel
Aquest treball de recerca explora la viabilitat de simular un sistema de telemetria i comunicació satelital emprant microcontroladors comercials de baix cost com l'ESP32 i Arduino.
